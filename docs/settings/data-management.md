# 数据管理

路径：**阅读器标题栏 → 设置 → 数据管理**。

![数据管理页中的设置导出导入、恢复默认和缓存分类](/screenshots/guide-13-data-management-v1.5.0.png)

<p class="image-caption">从“设置 → 数据管理”导出或导入设置 v9，并按类别检查缓存；导出排除翻译 Key 与 WebDAV 凭据，导入失败会回滚已应用字段。</p>

## 设置配置

### 导出设置

v9 导出文件包含当前版本规范化的 85 项图片、字体、布局、浮窗、外观、动画、性能、阅读和交互偏好，以及其他适用站点、AI 服务模型目录、翻译规则和 WebDAV 非敏感选项。仍兼容导入 v8、v7、v6 组合文件与 v5 偏好文件；只会按对应旧版本真实结构补齐当时不存在的模型目录、离线 Topic、通知历史和互动历史开关，损坏的 v9 文件不会套用旧版迁移规则。

不包含：

- 登录凭据和 Cookie；
- 帖子正文；
- 浏览历史；
- 阅读队列；
- 收藏、回应或原站账号数据；
- LDC 账户数据和成功缓存；
- API 响应缓存。

翻译 API Key、WebDAV 用户名和密码始终排除，不会以明文进入配置文件。

### 导入设置

1. 先导出当前设置作为备份。
2. 点击“导入设置”并选择配置文件。
3. 核对格式和版本提示；v6/v7/v8 会恢复各自版本的安全组合设置，旧 v5 文件只恢复偏好。
4. 确认导入。
5. 确认后由组合配置事务依次写入各自仓储，并立即投影到当前阅读器。

业务值仍按对应版本的设置规则规范化；版本号、设置计数、导出时间等元数据若类型错误，或当前 v9 缺字段、多字段，文件会直接拒绝。无效文件和取消确认都不会产生部分设置。任一步写入失败时，会逆序恢复已经写入的仓储。导入不会把另一个浏览器的登录状态或秘密凭据带到当前浏览器。

同 URL 的翻译服务会复用本机已有 API Key。WebDAV 地址相同且本机已有用户名、密码时会复用；地址变化或缺少凭据时，连接凭据保持为空并自动关闭定时同步。

0.1.14 新增独立的全屏布局字段。导入同版本、字段完整但尚未包含该字段的早期配置时，会自动补入全屏默认布局；其他缺失字段或版本不匹配仍会拒绝导入。

### 恢复全部默认 {#reset-settings}

该操作经确认后覆盖偏好、其他适用站点、翻译和 WebDAV 设置并立即投影，同时清除本机翻译 API Key、WebDAV 用户名与密码，并把阅读队列图标恢复到默认位置。它不会删除阅读队列条目、浏览历史或缓存，也不会撤销原站收藏、回应或通知状态。若只需恢复某一类设置，进入对应面板使用该面板自己的“恢复默认”。

v1.5.0 会再次为已有设置的用户递增“大版本设置更新”提示锚点；即使已经消费过 v1.3.1 的提示锁，升级后仍会收到一次新版默认值建议。选择“保留当前设置”不会改动任何值；选择“恢复默认值”会重置设置和阅读队列图标位置，但不删除队列条目、历史、下载记录、帖子缓存或账号数据。新用户首次安装仍保持静默，同一锚点不会重复提示。

![当前设置契约的一次性更新提示与重置入口](/screenshots/guide-30-settings-update-reminder-v1.5.0.png)

<p class="image-caption">设置契约升级时会显示一次性提示；选择重置只恢复阅读器设置和队列图标，不删除队列条目、历史、缓存、账号数据或原站内容。</p>

## 本地缓存

面板按六类展示数量、大小、保存位置和最长保留期：

| 类别 | 包含 | 清理时保留 |
| --- | --- | --- |
| 浏览历史与岁月史书 | 阅读位置、查看时间和服务器 404 后保留的岁月史书记录 | 浏览器自身访问历史、原站状态 |
| 帖子与楼层内容 | 帖子信息、楼层正文、回复关系、主题快照和接口缓存 | 离线 Topic HTML 与下载记录 |
| 用户资料卡 | 资料、徽章、用户组、关注列表、账户摘要、用户观察公开历史与采集断点 | 用户观察名单、Connect 近 400 天信任观察历史 |
| 通知与消息 | 通知分页、回复展开、已读投影和跳转位置 | 原站真实消息与未读状态 |
| 收藏、回应与其他数据 | 收藏列表、回应、点赞、译文及其他已登记通用响应 | 原站真实收藏与回应 |
| 头像、表情与原图 | 统一图片响应和三个精确登记的兼容 CacheStorage | 线上图片、其他站点或未知缓存 |

缓存面板只管理已映射到上述六类的记录。离线 Topic 产物和无法识别的永久记录不会被归入“其他数据”，避免选择性清理误删用户显式保留内容；统计总数也只计算实际受面板管理的记录。

“头像、表情与原图”会合并显示两类事实：当前 Lite 统一响应仓储中的图片 Blob，以及旧版/主线已经写入浏览器 CacheStorage 的头像、表情和灯箱原图。阅读器只识别自己登记的三个精确缓存名称，不会扫描或删除同站点其他缓存。缺少容量头时会读取 Blob 实际大小；某一类统计失败时会保留其他类别结果并显示“不完整”，不会把失败冒充成 0。

## 选择性清理

1. 勾选需要清理的缓存类别。
2. 核对条目数、容量和保留期。
3. 点击“清理已选缓存”，在二次确认中再次核对实际类别。
4. 确认后执行清理，再重新打开相关主题或面板，让阅读器按需重建数据。

二次确认会明确提示：这里只删除本机缓存，不删除站点账号或 WebDAV 远端数据；已同步记录可能在后续同步时重新合并回来。取消确认不会改变当前选择或缓存数据。

清理主题与楼层缓存会增加下一次打开主题的请求；清理用户资料不会删除账号或观察名单，但会清空观察公开历史、采集断点、待续传任务和当前会话内存投影，避免旧观察结果在持久层清空后重新写回。清理消息缓存不会把通知标记为已读。

清理图片资产时会依次处理阅读器登记的浏览器图片缓存、统一响应仓储和当前页面 Object URL。任一浏览器缓存删除失败都会显示失败并保留当前选择，避免把局部成功误报为全部完成；它不会建立或维护第二套图片写缓存。

清理浏览历史、通知或收藏/回应缓存时，会先等待正在进行的 WebDAV 同步结束并封锁新同步，再解除对应本机三方合并基线。屏障或基线写入失败时，该类别保持勾选且不执行本地删除；清理成功后释放屏障，下一次同步仍可从远端恢复尚未被业务删除的记录。清理本地缓存本身不会在远端生成删除标记。

若只有当前主题出现缓存异常，优先使用标题栏的“清除当前帖子缓存并刷新”入口。它会保留当前阅读锚点，只失效该主题及关联图片，再通过统一 Topic 打开事务重新获取；不要求手动清空所有缓存。

## 操作边界

| 操作 | 设置 | 本地业务记录 | 原站账号状态 |
| --- | --- | --- | --- |
| 导出设置 | 读取 | 不包含 | 不影响 |
| 导入设置 | 覆盖 | 不影响 | 不影响 |
| 恢复默认 | 覆盖 | 不影响 | 不影响 |
| 清理缓存 | 不影响 | 按选中类别删除 | 不影响 |
| 从收藏中心移除 | 不影响 | 同步更新 | 会改变 |

清理前先判断目标属于“配置”“缓存”还是“原站业务状态”，不要把三者混为一谈。

## 与 WebDAV 的区别

数据管理页只操作当前浏览器的设置导入导出与缓存；跨设备同步位于独立的 [WebDAV 同步](/settings/webdav-sync) 面板。WebDAV 可按类别合并历史、收藏、设置、阅读队列和阅读位置，也可单独启用通知与互动历史缓存。历史清单只含可搜索投影，不含原始分页响应、请求游标或限流状态；只有用户单独开启“离线 Topic 下载”后，完整 HTML 才以独立对象同步。

清理本地缓存不等于删除远端同步记录。若需要验证另一浏览器能否恢复队列，应先在来源浏览器完成一次成功同步，再在目标浏览器使用同一账号、地址和远端文件执行“立即同步”。
