# WebDAV 同步

路径：**阅读器标题栏 → 设置 → WebDAV 同步**。

![设备 A、WebDAV 远端文件与设备 B 之间的合并同步流程](/screenshots/guide-29-webdav-sync-v1.1.0.svg)

WebDAV 用一个小型 JSON 文件在多个浏览器之间交换本地记录。同步会先读取远端文件，以本机上次成功同步的基线执行三方合并，再通过 ETag 条件写入；不是拿某一端整份覆盖另一端，也不是只上传本机新增。远端在同步期间被其他设备修改时，阅读器会重新读取并重试，不会把 412 冲突当成成功。

## 坚果云配置

在坚果云安全设置中创建第三方应用密码，然后填写：

| 字段 | 坚果云示例 | 说明 |
| --- | --- | --- |
| WebDAV 地址 | `https://dav.jianguoyun.com/dav/` | 必须使用 HTTPS，地址中不能嵌入用户名或密码 |
| 用户名 | 坚果云账号邮箱 | 不是昵称 |
| 应用密码 | 单独创建的第三方应用密码 | 不使用坚果云登录密码 |
| 远端文件 | `ALR-Lite/v2/sync.json` | 必须同时包含目录和文件名，目录缺失时自动创建 |

凭据只保存在 userscript 专属存储，不写入远端 JSON、设置导出、请求 URL 或显式业务请求头。保存后先点“测试连接”，成功后再点“立即同步”。

## 可选同步内容

九类数据分别开关，关闭的类别不会上传、下载或删除：

| 类别 | 同步内容 | 明确不包含 |
| --- | --- | --- |
| 浏览历史 | 主题、最近阅读楼层、已读楼层和查看时间 | 帖子正文 |
| 收藏记录 | 收藏链接、标题和定位信息 | 不替代或修改原站收藏 |
| 设置配置 | Lite 外观、布局、性能和阅读交互设置 | WebDAV 凭据 |
| 阅读队列 | 主题链接、固定状态和入口楼层 | 帖子正文 |
| 阅读位置与窗口状态 | 最近位置、讨论窗口锚点和全屏窗口几何 | 页面 DOM |
| 自定义适用站点 | 用户添加的 HTTPS Discourse 站点 | 登录会话 |
| Connect 本机观察历史 | Connect 指标历史和服务器确认已读指纹 | Cookie 与接口响应正文 |
| AI 翻译服务集合 | API URL、模型、温度、思考等级、RPM / TPM、动画与 Prompt；API Key 使用 WebDAV 应用密码加密 | WebDAV 密码、未加密 API Key |
| 已翻译 Section 缓存 | 最近使用的译文 Section | 原文、页面 DOM |

帖子正文、图片、附件、短期限流状态和页面缓存永不进入 WebDAV 文件。默认只启用浏览历史、收藏记录和阅读队列；翻译服务集合与译文缓存必须分别主动开启。应用密码变化会导致已有加密 API Key 无法解密，应先在原配置完成同步并记录旧密码对应关系。

## 手动同步与首次同步

“立即同步”始终执行合并：

1. 读取远端文件及 ETag。
2. 比较本机记录、远端记录与上次成功同步基线。
3. 合并新增、更新和删除标记。
4. 条件写入成功后，才把合并结果应用到本机并更新基线。

因此，在新浏览器中清空本地队列后再同步，只要远端仍保存队列记录，就会下载并显示；如果某台设备在一次成功同步后明确删除队列项，该删除会作为删除标记传播。认证失败、远端 404 后创建失败、网络中断或冲突重试耗尽时，本机现有记录不会被清空。

## 定时同步

定时同步默认关闭。启用后仅在页面可见时运行，启动后先等待 30 秒，再按所选间隔串行执行。可选间隔为 15 分钟、30 分钟、1 小时、3 小时和 6 小时；坚果云按请求计数，通常建议 1 小时。

切换设备后需要立刻看到变化时，直接使用“立即同步”，不必等待下一次定时任务。多个标签页或设备同时同步时仍走同一 ETag 冲突处理，不会静默覆盖较新的远端文件。

## 故障判断

- `401` 或 `403`：检查账号邮箱和第三方应用密码，不要改用登录密码。
- `404`：连接测试只验证 WebDAV 根地址和账号；首次正式同步发现远端文件不存在时会尝试创建目录和文件。若创建仍失败，检查远端路径是否包含目录与文件名。
- `412`：远端在本轮同步期间被其他设备更新，阅读器会重新读取并重试；持续出现时稍后再同步。
- 新设备没有记录：确认两端连接到同一个地址、账号和远端文件，并且对应类别在两端都已开启。
- 清空后记录消失：区分“只清了本地缓存”与“成功同步过删除”。前者可从远端恢复；后者会传播删除标记。
- 翻译 API Key 解密失败：确认当前 WebDAV 应用密码与加密该配置时一致；阅读器不会把无法解密的 Key 当成空值覆盖远端。

修改远端路径相当于切换到另一份同步文件，不会自动迁移旧路径内容。更换账号或路径前先在现有配置执行一次成功同步，并记录原路径以便回退。
