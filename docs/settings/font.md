# 字体设置

路径：**阅读器标题栏 → 设置 → 字体设置**。

![字体设置页中的渲染、宿主文字和分作用域字体控件](/screenshots/guide-04-font-settings.png)

## 字体显示优化

| 开关 | 作用范围 |
| --- | --- |
| 启用字体显示优化 | 阅读器界面和正文 |
| 同时应用到原站页面 | 主题列表、原生主题页等原站区域 |

若页面还安装了其他字体渲染脚本，面板会提示环境状态。出现字重发黑、文字发虚或描边重复时，先只保留一套渲染，再刷新页面比较。

## 嵌入阅读列表文字

原站列表尺寸不会改变阅读器正文：

| 项目 | 默认 | 范围 |
| --- | ---: | ---: |
| 标题 | 110% | 50%–200% |
| 头像 | 80% | 50%–200% |
| 右下角信息 | 120% | 50%–200% |
| Label Card | 100% | 50%–200% |

修改后立即观察左侧原站列表，确认没有拥挤、截断或信息重叠。

## 三个字体作用域

| 作用域 | 典型内容 |
| --- | --- |
| 界面 | 标题栏、按钮、设置、时间轴和辅助信息 |
| 正文 | 帖子、引用、楼中楼、Onebox 和提示块 |
| 回复 | 回复编辑器及输入区域 |

每个作用域都可以设置字体、字重、颜色和字号。调整正文不会强制改变界面；回复编辑器也可以保持更紧凑的字号。

0.1.15 新配置的字号默认值为界面 92%、正文 95%、回复 80%。已有有效自定义值继续沿用。

## 字体选项

- 跟随站点；
- 当前系统字体；
- 中文无衬线；
- 衬线；
- 等宽；
- 自定义本机字体。

打开字体选择器时，阅读器会优先通过当前 LINUX DO 宿主页面提供的本地字体能力读取可用字体名称。浏览器可能要求授权；不支持、拒绝授权或读取失败时，菜单会显示相应状态，仍可使用预设字体或手动填写字体名称。

自定义字体只引用本机已安装的字体名称，不会上传字体文件，也不会让其他设备自动获得该字体。

## 配置步骤

1. 选择浮窗、全屏或移动。
2. 选择界面、正文或回复作用域。
3. 依次设置字体、字重、颜色、字号。
4. 需要跨形态一致的字段，单独开启链状共享按钮。
5. 点击底部“保存全部更改”。

每个字段独立共享。例如，可以共享字体家族和颜色，但让移动端字号更小。

## 调整建议

- 先定字体和字重，再调字号，最后调颜色。
- 正文字重优先使用 400 或 500；过高字重会压缩长帖阅读层次。
- 自定义颜色应在明、暗两种主题下分别检查对比度。
- 只出现原站页面异常时，关闭“同时应用到原站页面”，无需关闭阅读器内优化。
