# 更新记录

![关于面板中的当前脚本版本和项目版本信息](/screenshots/guide-14-about.png)

<p class="image-caption">更新记录以 userscript 元数据版本为事实源；关于面板用于核对当前页面实际运行的版本。</p>

## 0.1.7 — 阅读器全层性能强化

核验日期：2026-07-25。

- 保留单一 Reader Portal 与三形态共用内核，并统一设置、通知、历史、收藏等浮层的挂载、停放和销毁。
- 强化变高虚拟列表、离屏正文脱水、时间轴索引复用、滚动锚点、宿主滚动几何缓存与媒体生命周期，减少无效 DOM、布局读取和后台工作。
- 批量楼层渲染按主线程时间片主动让步；浮窗、设置和灯箱拖拽按帧合并几何更新。
- 收窄宿主、Header、Composer、主题列表和元数据观察范围；页面隐藏时暂停预取、实时更新、延迟水合与重试，回到前台后闭环恢复。
- 请求与资源诊断只在对应设置面板打开时启用详细取证，避免常驻调用栈与 Resource Timing 开销。

## 0.1.6 — 设置面板页面级适配

核验日期：2026-07-25。

- 嵌入态设置面板改为悬浮于整个页面，不再被阅读器工作区宽度约束。
- 设置面板、字体菜单、颜色选择器和帮助提示共用同一承载层，并在阅读形态切换时同步迁移。
- 页面级承载层继续使用容器查询；窄视口保持顶部横向分类、单列内容和紧凑尺寸，浮窗与全屏仍按阅读器尺寸适配。

## 0.1.5 — 统一阅读器内核与事件驱动更新

核验日期：2026-07-25。

- 摒弃 Shadow Root 和三套形态业务分支，以嵌入态作为唯一阅读器内核；浮窗、全屏只改变外层呈现，保留按容器宽度响应的窄屏布局。
- 通知与新信息改用 Discourse 事件信号更新，保留普通通知跳转、Boost 分类和聚合回复展开；移除对应的定时轮询旧路径。
- 回复提交继续拦截宿主自主跳楼层，同时保持阅读器内新楼层插入与定位。
- 统一设置、集合面板、生命周期与媒体查看器中的重复链路，并将静态 CSS 迁入不可变 `@resource`。
- 保留可维护的 `work/main.js` 作为 GreasyFork 发布源码；新增确定性压缩产物，仅用于仓库直装和体积审计。

## 0.1.4 — 内部精简与文档验收

核验日期：2026-07-24。

- 在业务、交互、请求和缓存行为不变的前提下，合并重复状态派生、分页、缓存查找与局部辅助链路。
- 收口阅读队列、灯箱、用户资料、设置和宿主工作区的监听注册与清理职责。
- 完善指南截图、操作图注以及图片登记、密度和完整性校验。

## 0.1.3 — 阅读队列与主题配色

核验日期：2026-07-24。

- 新增并完善多主题阅读队列：列表页独立加入、跨刷新恢复、可移动与贴边浮层、实际阅读进度、分层后台预加载、错误重试、固定和确认清理。
- 队列后台准备范围扩展到主楼层、楼中楼和相关图片；超长主题按开头与目标区域选取最多 200 个主楼层，并继续服从共享请求调度。
- 外观颜色自动生成明亮/暗色适应色，并支持单独关闭结构配色而保留原配置。
- 完善预加载楼层的已读同步、进入动画，以及虚拟流向上加载时的锚点稳定性。
- 收窄首楼分隔线和特殊帖子样式，避免无关内容被误改。
- 使用指南按入口、操作和结果补齐分步截图与操作说明，并增加图片登记、密度和说明完整性检查。

## 0.1.2 — 正式手册基线

核验日期：2026-07-23。

本版首次建立可自动验证的正式用户手册和功能目录。目录覆盖当前源码中的用户可见能力：

- 五种阅读形态、多主题队列、虚拟化连续阅读与楼中楼；
- 时间轴、历史前后切换、只看楼主、父回复和引用上下文；
- 原图灯箱、评论、下载、音视频、HLS、公式、投票和代码预览；
- 回复、点赞、回应、Boost、收藏、通知级别和权限操作；
- 消息、历史、收藏/回应、用户卡与关系操作；
- 13 个设置面板、分形态配置和按字段共享；
- 缓存、资源监控、请求数据、429 协调和 Cloudflare 恢复；
- 安装、隐私、兼容性和故障排查。

::: info
这里的“基线”表示已用当前源码和运行界面核对，不代表每项功能都在 0.1.2 才首次实现。缺少可靠历史证据时，不反推早期引入版本。
:::

## 0.1.0 — 早期公开介绍

仓库曾以 `0.1.0` 维护项目介绍素材，但没有可验证的逐功能更新记录。本手册不据此推断旧版功能清单。

## 维护规则

后续每次用户可见变化必须同步更新：

1. 对应功能项的 `version`、`last_verified`、`source_anchor` 和文档映射；
2. 受影响页面 frontmatter；
3. 本更新记录；
4. 必要的脱敏截图；
5. `npm run docs:verify` 结果。
