## 1.5.0 — 共享工具工作区与四文件构建

核验日期：2026-08-16。

### 重要特性

- 再次递增已有用户的设置恢复提醒锚点；已经消费 1.3.1 提示锁的用户升级后仍会收到一次新版默认值建议，新用户保持静默，选择保留不会改动任何数据。
- 通知与私信、浏览历史、收藏与回应、Topic 下载、用户观察、岁月史书和不想看统一进入共享多标签浮窗；窗口位置、尺寸、冻结、标签数量和跨标签页状态沿用同一套框架。
- 收藏与通知改用可续传的分页集合仓储，筛选只改变当前视图，不改变标签总数；后台补页、缓存恢复、实时消息和跨标签页刷新继续保持一致状态。
- 用户观察按公开活动渐进整理主题、帖子、回应、解决方案与投票；观察自己时额外合并当前账号的私信和收藏投影，并明确区分账号私有信息与公开活动。
- 岁月史书保留服务器已 404、但本机仍有正文快照的 Topic；不想看支持类别、标签、楼主、楼层用户和字符规则，命中原因可追溯、筛选和批量恢复。
- 暗色主题可按当地日落或固定时间自动启用，并在日出恢复此前模式；位置、时区或太阳时刻不可用时保持用户当前主题，不猜测切换。
- 请求调度、缓存身份、长帖虚拟化、已读状态、阅读队列、离线 Topic 和 WebDAV 合并链同步加固，继续遵守 429、Cloudflare 与敏感配置边界。
- 设置组合格式收紧为 v9：仅 v6/v7/v8 使用对应旧结构迁移，损坏的 v9 不再静默补字段；翻译配置持久化失败不会先污染运行态快照，三类秘密仍保持零导出。
- v5–v9 配置元数据改为精确类型校验，字符串版本号或计数、错误时间类型和未知顶层字段不再通过隐式数字转换进入导入事务。
- WebDAV 遇到主文件、账号 scope、类别或记录无墓碑消失时改为保留本机并安全重建；未知未来类别会透传，已勾选但缺少运行时端口的类别会阻止整轮假成功。
- WebDAV 补齐 1.3.0 后有意义字段的合并与类型门：历史分类/标签/精确锚点、模型目录、加密信封和离线归档状态都参与校验；旧离线清单缺少归档状态时仍可安全升级。
- 快捷方式导入与录制共用扩展后的浏览器保留键和真实键码门禁，数字小键盘遵循无修饰键规则，右键不被录制；消息/历史/收藏动作可恢复指定共享标签。
- 清理历史、通知和收藏/回应缓存前会封锁对应 WebDAV 同步，防止旧数据在清理事务中回灌；清理用户资料时同步清空观察历史、断点和内存投影，但保留观察名单。
- 六类缓存的批量清理新增危险操作二次确认，确认框逐项列出实际类别；离线 Topic 与未知永久记录不归入通用响应，也不进入受管总数。

### 工程与文档

- Greasy Fork 预备构建由三文件升级为薄 Loader + Core + Platform + Features 四个可执行文件；CSS 仍是固定 Git 提交与 SHA-256 的 `@resource`，不是第五个执行文件。
- 本地调试入口同时生成单文件版和四文件版，并核对元数据、CSS、全部源码模块哈希、manifest、运行契约和 `main-lite` / `mian-lite` 兼容副本；结构不同，但用户功能载荷必须一致。

## 1.3.0 — 离线 Topic 与安全配置

核验日期：2026-08-11。

### 新增特性

- 新增 Topic 下载窗口，可按全部楼层、只看楼主或自定义楼层在后台补齐正文；完成后可离线查看、保存独立 HTML，并搜索或批量管理下载历史。
